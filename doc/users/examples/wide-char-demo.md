# 🌏 宽字符演示

本文档展示如何处理中文、日文等宽字符。

---

## 📚 什么是宽字符？

**宽字符**（Full-width characters）是指在东亚文字中占据两个标准字符宽度的字符，包括：
- 中文汉字
- 日文假名
- 韩文谚文
- 全角标点

**特点**:
- 视觉宽度 ≈ 2 × 英文字符
- 需要特殊处理以保持比例

---

## 🎯 示例 1: 基础中文文本

```bash
python unicodeart.py \
  -t "你好世界" \
  --font "C:\Windows\Fonts\SimSun.ttc" \
  --height 20 \
  --matrix 6
```

**关键参数**:
- `--font`: 必须使用支持中文的字体
- `--matrix 6`: 平衡质量和速度
- **无需指定 ratio**: 默认 2.0 是标准值

**重要说明**:
- `--ratio=2.0` + `--wide-char-ratio=2.0` 确保中英文正确显示
- 在混合等宽字体环境中（VSCode、现代终端），这是唯一正确配置

---

## 🎯 示例 2: 中日韩混合

```bash
python unicodeart.py \
  -t "Hello 你好 こんにちは 안녕하세요" \
  --font "C:\Windows\Fonts\MSYH.TTC" \
  --height 15
```

**说明**:
- 微软雅黑支持多语言
- 使用默认 `--ratio 2.0` 即可正确显示

---

## 🎯 示例 3: 图片中的宽字符识别

```bash
python unicodeart.py \
  -i chinese_text_photo.jpg \
  --height 30 \
  --wide-char-ratio 1.5
```

**调整 `--wide-char-ratio`**:
- **1.5**: 优先使用中文字符
- **2.0**: 默认平衡
- **3.0**: 谨慎使用中文

---

## 🎯 示例 4: 自定义宽字符集

```bash
python unicodeart.py \
  -i photo.jpg \
  --height 30 \
  --wide-chars "一二三四五六七八九十百千万"
```

**用途**:
- 限制使用的中文字符
- 特定风格创作
- 减少匹配时间

---

## ⚙️ 宽字符配置详解

### `--wide-char-ratio` 调优指南

| 值 | 行为 | 适用场景 |
|----|------|---------|
| 1.0-1.5 | 积极使用宽字符 | 特殊艺术效果 |
| 2.0 | 标准（默认） | **推荐**：配合 `--ratio 2.0` 确保中英文对齐 |
| 2.5-3.0 | 保守使用宽字符 | 极少使用，可能导致显示过窄 |

**测试脚本**:
```bash
for wide_ratio in 1.5 2.0 2.5; do
  python unicodeart.py -t "A中B文" \
    --font "SimSun.ttc" \
    --wide-char-ratio $wide_ratio \
    --height 15 \
    -o "test_wide_ratio_${wide_ratio}.txt"
done
```

## 💡 常见问题

### Q1: 中文字符显示为方块？

**原因**: 字体不支持中文

**解决**:
```bash
# Windows
--font "C:\Windows\Fonts\SimSun.ttc"

# macOS
--font "/Library/Fonts/PingFang.ttc"

# Linux
--font "/usr/share/fonts/truetype/wqy/wqy-zenhei.ttc"
```

---

### Q2: 中英文混排时对齐问题？

**原因**: `--ratio` 或 `--wide-char-ratio` 设置不当

**解决**:
1. **保持默认值**: 不要随意修改 `--ratio` (默认 2.0) 和 `--wide-char-ratio` (默认 2.0)
2. **检查终端**: 确保终端使用等宽字体 (如 Consolas, Menlo, Sarasa Mono 等)
3. **避免使用非等宽字体**: 如微软雅黑在非等宽模式下可能导致微小错位
